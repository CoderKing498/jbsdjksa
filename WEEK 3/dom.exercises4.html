01 Cambiar texto con textContent textContent
💡 textContent lee o reemplaza el texto de un elemento sin interpretar HTML. Para leer: el.textContent. Para escribir: el.textContent = "nuevo texto". Es más seguro que innerHTML cuando solo necesitas texto.

Al hacer clic en el botón, toma el valor del input y ponlo dentro de <p id="salida-1"> usando textContent. Si el input está vacío, no hagas nada.

💡 innerHTML interpreta el string como HTML real. Puedes meter etiquetas como <strong>, <em>, <ul><li>. ⚠️ Nunca pongas datos del usuario directamente (riesgo XSS).

03 Seleccionar elementos del DOM getElementById · querySelector · querySelectorAll
💡 getElementById("id") busca por ID (sin #). querySelector(selector) acepta cualquier selector CSS y devuelve el primer match. querySelectorAll devuelve todos como NodeList — recórrela con forEach.

04 Crear e insertar elementos createElement · appendChild
💡 createElement("tag") crea un nodo en memoria — aún no está en la página. appendChild(el) lo inserta al final del padre. Flujo: crear → configurar (textContent, clases…) → insertar.

Al hacer clic en "+ Agregar", crea un <li> con el texto del input y añádelo a <ul id="lista-4"> con appendChild. El botón "Limpiar" vacía la lista con innerHTML = "". Si el input está vacío, no agregar.
